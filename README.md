# Medical Brain · demonstração

Painel de estudos de Medicina em formato de hospital: plantão do dia, agenda de provas, prontuários por patologia, drills de habilidades clínicas, casos, Anki e notas.

**Esta é uma versão de demonstração, com dados fictícios.** Ela roda 100% no navegador (sem servidor e sem banco): o estado fica salvo apenas no `localStorage` do visitante.

A versão pessoal roda localmente (Node.js + SQLite) e não está neste repositório.

- `index.html` e `*.js`: o painel (HTML, CSS e JavaScript puros)
- `demo.js`: cria o estado fictício na primeira visita
- `seed.js`: conteúdo de apoio (habilidades, patologias, prompts)

Projeto independente de Helen Lavigne Almeida Martins. Não substitui orientação médica nem material de estudo oficial.
